其实这不是第一次写博客，学生时代的QQ空间、百度空间都留下过自己的文字，还有逝去的人人网，现在在用的豆瓣以及公众号。
忽然想起来在几年前，使用WordPress建过一个博客，还弄了域名，但是比较麻烦，写了一篇就放弃使用了。

今年对于我来说是AI的元年，开始使用龙虾（OpenClaw），在尝试了QClaw、WorkBuddy、Codex之后，目前还是觉得QClaw比较顺手，今年的AI工具蓬勃发展，从龙虾到爱马仕再到Codex，国产的一众龙虾助手，你方唱罢我登场，我倒是觉得找一个用的习惯的，开始上手使用做出一些东西才好。就像摄影一样，初学不用太纠结用什么设备。

扯远了，说回来，最近在上论坛，看到很多人分享自己的博客，分享搭建博客的心得体会，恰逢近日比较闲暇，也就想着用AI帮我分析一下搭建的难度，从论坛得知了 GitHub page，Cloudflare page， NotionNext三种免费方案，对比发现 Github page 最简单。

说干就干，让QClaw帮忙部署，三下五除二搭建好了，调整了几处设置，就可以访问了。

那么就从这一篇开始把，AI时代的，我的第一篇博客。
